\chapter{知识、理解与智慧为什么有价值}
\chaptergoals{区分真信念价值、知识附加价值和能力成就；理解知识与理解的差异；分析智慧、认识能动性和目标冲突；能够设计不只奖励答案的评价方案。}

\begin{openingcase}
学生背熟了气候系统的所有结论，却无法解释变量改变会带来什么后果；另一位学生使用含有理想化假设的模型，能够说明主要依赖关系，也知道模型会在哪里失效。谁拥有更多知识，谁拥有更深理解？若可靠过程只把同一个真答案送到手中，它增加了什么价值？这些问题要求我们从“是否为真”转向认识成就的结构与用途。
\end{openingcase}

\minitopic{研究定位}价值问题已从“知识是否比真信念更好”扩展为理解、品格和共同探究的多元评价。\textcite{pritchard2010}整理知识价值争论，\textcite{elgin2017}与\textcite{khalifa2017}给出不同的理解模型，\textcite{whitcomb2017}则把承认限度本身作为可分析的智识品格。

\begin{checkpoint}
知识的价值不能只由已经得到的真值解释；可靠性、能力成就、稳定性和信任资格分别提供候选答案。理解要求把握关系并能迁移、反事实推演和定位失败，智慧还要求选择值得追问的问题并承认边界。
\end{checkpoint}

\begin{exercises}
\begin{enumerate}
  \item 固定一个信念已经为真，分别说明可靠来源可能增加稳定性、成就、可传递性或行动资格中的哪项价值。
  \item 比较沼泽化问题与Gettier问题：二者都涉及真理和过程，但攻击目标有何不同？
  \item 各构造一个“知道却不理解”和“使用理想化模型但有理解”的案例。
  \item 为理解提出三项可观察测试，并用机械背诵者与模型使用者检验。
  \item 分析一项容易获得的证言知识：成就功劳应如何分配给听者、说话者和制度？
  \item 设计一套课程评价方案，同时奖励正确、解释、迁移、校准与错误修正，并防止重复计分。
\end{enumerate}
\end{exercises}
