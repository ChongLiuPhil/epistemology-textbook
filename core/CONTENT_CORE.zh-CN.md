# Content Core — 教材内容原则

**角色：** 保存稳定的教材内容与学习方法原则。它不是正文摘要，也不替代九章 QMD。

## 项目目的与性质

《我们如何知道？——问题驱动的认识论》首先是一项**学习过程中的认识论材料整合、比较与问题化梳理工程**，同时形成可供中国学生、自学者与课程使用的结构化教材。

本项目不把“提出作者原创认识论体系”设为主要目标。原创区分、判断或理论发展可以在学习和整理过程中自然出现，但不应为了证明原创性而制造额外理论负担。

作者的判断性角色主要体现在：

- 选择哪些问题值得作为学习入口；
- 决定哪些材料、立场与文献应被并置比较；
- 判断概念区分是否清楚、论证是否成立、反例是否击中目标；
- 决定历史材料在当前哲学问题中承担什么作用；
- 审核解释视角、比较边界、教学层次与全书组织路径。

因此，“资料整合”不等于机械汇编；材料的选择、重构与组织本身包含需要作者审核的哲学和教学判断。

## 哲学学习与研究的方法立场

本书采用问题导向的哲学观：

- 哲学研究首先面对问题、概念、理由、反例和论证，而不等同于研究某位前人“说过什么”；
- 对哲学家思想的研究、思想史研究、哲学史研究都具有独立价值，但它们与直接研究一个哲学问题并不是同一种任务；
- 历史材料可以帮助提出问题、澄清概念、理解论证来源或暴露被忽略的选项，但不能以历史归属本身替代哲学论证；
- 学习哲学的重要目标，是训练读者提出问题、重构理由、比较解释、识别前提、检验反例并形成可辩护的判断。

这一立场是教材组织原则，不要求各章反复进行元哲学论述。

## 当前稳定内容原则

- **问题驱动**：章节围绕认识论问题推进，不以人物或流派的简单编年/罗列作为主要组织方式。
- **先重构、后评价**：介绍立场时先准确呈现其理由，再进入批评、比较或作者判断。
- **整合而非堆砌**：材料进入正文时必须说明它解决什么问题、与哪些竞争解释相关，而不是把阅读笔记直接并列。
- **教学层次可辨认**：基础解释负责建立问题与核心论证；扩展、研究入口和练习再增加争议、案例与技术细节。
- **争议透明**：对存在实质争议的哲学主张，不把单一解释写成无争议事实。
- **术语一致**：核心术语的首次解释、正文跨章用法与术语表应保持一致；修改关键术语时需要跨文件检查。
- **证据可追溯**：学术性主张、重要历史归属和研究入口应尽可能由可核验文献支持，正式 citation key 进入根目录 `references.bib`。
- **反例与异议有位置**：重要理论不只呈现支持理由，也应让读者看到关键反例、限制或竞争解释。

## 人类责任主体

AI Agent 可以广泛参与检索、核查、综合、起草、重组、引用检查、网页维护和质量审计，但这不改变项目的责任结构：

- 作者 Chong Liu 保持为项目学习目的、问题框架与整体方向的责任主体；
- 材料选择、解释性判断、比较方式、教学组织和重大 Architecture 由作者审核；
- 具体正式公开版本的 Release Approval 由作者作出；
- AI 提议在被作者明确接受前，不得进入本 Core 作为稳定作者承诺。

该规则不要求作者对每一处资料性转述“提出原创理论”，而要求作者对最终选择、组织、判断和发布负责。

## 不由本文件决定的事项

- 网页主题、导航与构建方式属于 Form / Protocol；
- 具体章节段落仍以 canonical QMD 为准；
- AI 提议的新理论框架、术语或大规模重排，在作者明确接受前不是本文件中的稳定承诺。

## 开放问题

当前没有阻止日常教材维护的 CONTENT blocker。若未来出现会改变全书问题框架、关键概念关系、材料解释方式或章节功能的高影响歧义，应先进入 Working Memory clarification。
