# Content Core — 教材内容原则

**角色：** 保存已经由项目确立的长期内容原则。它不是正文摘要，也不替代九章 QMD。

## 项目性质与目的

《我们如何知道？——问题驱动的认识论》首先是一项**学习—整合—梳理型的认识论教材工程**：以作者持续学习认识论的过程为基础，对概念、问题、论证、文献、案例与研究路径进行选择、组织、比较和重构，服务系统学习、自学、教学与进一步研究。

本项目**不以建立一套作者原创认识论理论体系为主要目标**。可以包含作者自己的判断、分类、解释或立场，但不为了制造“原创理论”而强行统一材料；当作者性判断承担实质论证功能时，应尽量让其与文献重构、通行观点和教学性组织区分清楚。

作者判断主要体现在：

- 哪些问题值得先提出；
- 哪些材料、文献和争议应被纳入；
- 不同观点如何比较、排列与建立概念关系；
- 哪些反例、限制与争论最能帮助读者理解问题；
- 哪些知识适合基础层、扩展层与研究入口；
- 如何把哲学研究组织成可继续思考的问题，而不是前人观点的目录。

## 哲学教育取向

本书采用问题驱动结构，也承载一种明确的教学判断：**哲学研究不能被简单等同于研究前人的思想。**

思想研究、思想史研究、哲学史研究都可以是重要工作，但哲学研究还要求直接面对问题、区分概念、提出理由、比较论证、构造反例并检验立场。学习哲学史和哲学家的思想可以服务这些工作，却不自动替代这些工作本身。

这一取向尤其希望帮助中文学习环境中的读者形成更清楚的区分：学习“某位哲学家说过什么”与学习“一个哲学问题怎样被提出、论证和继续研究”不是同一件事。

这是一项项目级教学与组织原则，不要求正文专门设置大篇幅方法论宣言；应主要通过章节问题、论证组织、练习、研究工作坊和阅读路线体现。

## 当前稳定内容原则

- **问题驱动**：章节围绕认识论问题推进，不以人物或流派的简单编年/罗列作为主要组织方式。
- **整合而非强制原创**：优先准确梳理已有研究、争论与材料，不为追求“新理论”而制造不必要的统一。
- **先重构、后评价**：介绍立场时先准确呈现其理由，再进入批评、比较或作者判断。
- **作者判断可识别**：材料选择、问题排序、比较框架与评价性判断应尽量与文献中的原始立场区分。
- **教学层次可辨认**：基础解释负责建立问题与核心论证；扩展、研究入口和练习再增加争议、案例、技术细节与进一步文献。
- **争议透明**：对存在实质争议的哲学主张，不把单一解释写成无争议事实。
- **术语一致**：核心术语的首次解释、正文跨章用法与术语表应保持一致；修改关键术语时需要跨文件检查。
- **证据可追溯**：学术性主张、重要历史归属和研究入口应尽可能由可核验文献支持，正式 citation key 进入根目录 `references.bib`。
- **反例与异议有位置**：重要理论不只呈现支持理由，也应让读者看到关键反例、限制或竞争解释。

## 人类责任主体

AI Agent 可以广泛参与检索、核查、综合、起草、重组、引用检查、网页维护和质量审计，但这不改变项目的责任结构：

- 作者 Chong Liu 保持为教材项目目的、问题选择与整体组织的责任主体；
- 关键取舍、评价性判断与重大 Architecture 授权由作者负责；
- 具体正式公开版本的 Release Approval 由作者作出；
- AI 提议在被作者明确接受前，不得进入本 Core 作为稳定作者承诺。

该规则是本项目的协作治理原则，不试图在此解决一般性的 AI authorship 理论问题。

## 不由本文件决定的事项

- 网页主题、导航与构建方式属于 Form / Protocol；
- 具体章节段落仍以 canonical QMD 为准；
- AI 提议的新理论框架、术语或大规模重排，在作者明确接受前不是本文件中的稳定承诺。

## 开放问题

当前没有阻止日常教材维护的 CONTENT blocker。若未来出现会改变全书核心问题、材料组织原则、关键概念关系或章节功能的高影响歧义，应先进入 Working Memory clarification。
